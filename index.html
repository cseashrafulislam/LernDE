QUALITY GOVERNANCE

How LernDE avoids teaching wrong German

সহজ explanation হবে, কিন্তু shortcut কখনো actual grammar rule replace করবে না।

1

Canonical content

Vocabulary/phrase/grammar facts একবার define হয়; সব module একই data reuse করে।

2

Pronunciation hierarchy

German audio → standard pronunciation → Bangla approximation. Bangla লেখা authoritative pronunciation নয়।

3

CEFR scope

Current product scope Foundation, A1, A2, B1, B2. C1/C2 content intentionally excluded.

4

No fake official claims

Mock tests are original practice. They are not presented as official Goethe/telc exam papers.

5

AI does not overwrite truth

Static verified course content remains canonical. Optional AI integrations should only assist, not silently edit curriculum facts.

6

Versionable data

Content is separated into data files so reviews, corrections and future expansion can be audited safely.

Important: এই ZIP-এর translator intentionally course-aware and deterministic. Full unrestricted free-text translation requires a server-side translation/AI provider; API key কখনো static frontend-এ hard-code করা উচিত নয়।
